# 질문 코치

수학 학원에서 학생이 질문하러 오면 대화를 녹음하고, 학생의 말을 근거로 약점과 티칭 방식을 정리해 주는 휴대폰용 웹앱입니다.

## 쓰는 법
1. 휴대폰 크롬에서 이 앱 주소를 열고, 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있어요.
2. 오른쪽 위 설정(⚙)에서 OpenAI API 키(받아쓰기)와 Anthropic API 키(분석)를 입력해요.
3. 학생을 추가하고, 학생 이름을 누르면 녹음 화면이 열려요. 녹음을 끝내면 자동으로 받아쓰고 분석해요.
4. 수업이 끝나면 홈의 "하루 마감 · 오늘 리포트"에서 하루 리포트를 만들어요.

## 데이터와 개인정보
- 학생 이름, 기록, API 키는 모두 이 휴대폰 브라우저 안에만 저장돼요. 이 저장소에는 코드만 있어요.
- 받아쓰기는 OpenAI, 분석은 Anthropic으로 보내요. 학생 이름 대신 학생 번호(S001 등)만 보내요.
- 녹음 파일은 기본적으로 분석이 끝나면 지워져요(설정에서 보관 가능).
- 브라우저 데이터를 지우면 기록도 사라지니 설정의 "백업 받기"로 가끔 백업해 두세요.

## 구조
- `index.html`, `style.css`, `app.js`: 화면
- `api.js`: 받아쓰기(OpenAI `gpt-transcribe`)와 분석·하루 리포트(Claude) 호출
- `db.js`: 기기 안 저장소(IndexedDB)
- `vendor/anthropic-sdk.js`: Anthropic SDK(@anthropic-ai/sdk 1.12.0) 브라우저용 번들
